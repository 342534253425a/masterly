# ADR-0011. Права субъекта ПДн через события identity.account.v1

- Статус: принято
- Дата: 2026-10-28

## Контекст

ПДн пользователя разбросаны по сервисам: заявки, переписка, отзывы, уведомления, фото, аналитика, кейсы
модерации. Удаление аккаунта и отзыв согласия должны исполняться везде, причём в разные сроки: публичное —
сразу, данные под обязательным хранением — после срока. При этом нельзя нарушить владение данными, то есть
лезть в чужие БД.

## Решение

- identity — источник истины для аккаунта и согласий. Он публикует в `identity.account.v1` (ключ — `user_id`)
  события `AccountDeletionRequested` (с `retain_until`) и `ConsentChanged`.
- **Каждый сервис, хранящий ПДн, подписан на топик** (ACL в [`kafka.tf`](../../infra/terraform/kafka.tf)) и сам
  исполняет политику для своих данных:
  1. сразу удаляет или скрывает публичные ПДн (имя в отзывах → «Пользователь удалён», аватар, профиль);
  2. обезличивает остальное: заменяет на псевдоним, удаляет контакты из заявок и переписки;
  3. ставит окончательное удаление в план на `retain_until` (legal hold).
- **Учёт исполнения.** Каждый сервис отправляет identity подтверждение по gRPC. identity хранит статус
  исполнения по сервисам и алертит, если кто-то не уложился в срок.
- **Отзыв согласия на аналитику.** Шлюз перестаёт принимать события, analytics удаляет данные по `user_hash`
  пакетной мутацией.
- **Срок хранения топика — 30 дней,** чтобы сервис, лежавший неделю, всё равно получил событие.

## Последствия

- **Плюсы.**
  - Владение данными не нарушается.
  - Новый сервис подключается к политике подпиской.
  - Исполнение наблюдаемо и доказуемо (статусы, аудит).
- **Минусы.**
  - Удаление растянуто во времени (секунды–минуты), а не атомарно.
  - Каждый сервис обязан реализовать обработчик. Это закреплено контрактным тестом «после события сервис не
    возвращает ПДн».

## Альтернативы

- **Центральный сервис приватности с прямым доступом к БД** — нарушает изоляцию и ломается при каждой смене
  схемы.
- **Синхронный обход сервисов по gRPC** — хрупко: один недоступный сервис блокирует удаление, нужна своя
  машина повторов.
