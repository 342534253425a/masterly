# ADR-0008. Yandex Cloud: managed-хранилища, Kubernetes только для stateless

- Статус: принято
- Дата: 2026-10-28

## Контекст

ПДн граждан РФ должны храниться в РФ (152-ФЗ). Нужны три зоны доступности, а команда небольшая: дежурства по
самостоятельно развёрнутым Kafka, PostgreSQL и OpenSearch съели бы время продуктовой разработки. При этом
хочется сохранить переносимость и не привязывать код к облаку.

## Решение

- **Yandex Cloud, регион `ru-central1`, зоны a, b, d.**
- **Managed Kubernetes только для stateless-нагрузки:** web, gateway, доменные сервисы, потребители. Пулы узлов
  разделены по зонам, автоскейлер работает в каждой зоне отдельно.
- **Состояние — в managed-сервисах:** PostgreSQL, Kafka, Valkey/Redis, OpenSearch, ClickHouse, Object Storage.
  Бэкапы, failover, обновления и мониторинг берёт на себя провайдер.
- **Безопасность:** KMS (шифрование бакетов, секретов, ключей приложения), Lockbox → External Secrets,
  Certificate Manager, Smart Web Security.
- **Вся инфраструктура описана в Terraform** ([`infra/terraform`](../../infra/terraform)), приложения — в Helm и
  Argo CD (GitOps).
- **Переносимость — на уровне протоколов.** Код знает только PostgreSQL wire protocol, Kafka API, Redis API,
  S3 API, OpenSearch REST и OTLP. Облачных SDK в доменном коде нет.

## Последствия

- **Плюсы.**
  - Соответствие требованиям локализации.
  - HA и PITR из коробки.
  - Инфраструктура воспроизводима из кода.
  - Переезд к другому провайдеру РФ требует переписать Terraform-модули, но не приложения.
- **Минусы.**
  - Зависимость от возможностей и версий managed-сервисов (например, версия Kafka отстаёт от локальной 4.x).
  - Стоимость выше, чем у самостоятельно развёрнутых кластеров на том же железе.
  - Один регион. Межрегиональный резерв строится на бэкапах и IaC
    ([resilience.md](../architecture/resilience.md#10-аварийное-восстановление)).

## Альтернативы

- **Stateful в Kubernetes через операторы** (Strimzi, CloudNativePG, OpenSearch Operator). Полный контроль и
  ниже стоимость, но дежурства и экспертиза по каждой системе. Вернёмся к этому, если managed-ограничения
  начнут мешать.
- **Другие облака РФ** (VK Cloud, Selectel, SberCloud) — технически пригодны. Выбор определили набор
  managed-сервисов (OpenSearch, ClickHouse, Kafka) и три зоны в одном регионе.
- **Зарубежные облака** — недопустимы для ПДн.
