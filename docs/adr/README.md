# Журнал архитектурных решений (ADR)

ADR фиксирует значимое решение: контекст, выбор, последствия и отвергнутые варианты. Решения не переписываются
задним числом. Если решение меняется, пишется новый ADR со статусом «заменяет ADR-NNNN», а у старого статус
меняется на «заменено».
